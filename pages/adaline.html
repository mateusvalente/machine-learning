CAPÍTULO 03 · ADALINE

Aprender com a saída linear antes de decidir.

ADALINE significa Adaptive Linear Neuron. Ela calcula um valor contínuo, mede a distância até a resposta desejada e ajusta seus parâmetros com a Regra Delta/LMS.

PERCEPTRON RULE × REGRA DELTA

A soma é a mesma. O ponto onde medimos o erro é diferente.

Perceptron e ADALINE calculam o mesmo potencial u = Σ(wᵢxᵢ) + b. A diferença aparece no treinamento: o Perceptron compara o alvo com a classe produzida pelo degrau; a ADALINE compara o alvo diretamente com a saída linear.

REGRA DO PERCEPTRON

O erro é calculado depois da decisão.

Primeiro o potencial atravessa a função Step. Depois, a classe prevista ŷ é comparada com o alvo y.

Forwardu = Σ(wᵢxᵢ) + b
ŷ = Step(u)Erro e atualizaçãoeP = y − ŷ
wᵢ ← wᵢ + ηePxᵢ
b ← b + ηeP
Como ŷ é discreto, o erro informa principalmente se a decisão foi correta e em qual direção corrigir.

ADALINE · REGRA DELTA/LMS

O erro é calculado antes da decisão.

O alvo d é comparado diretamente com o potencial contínuo u. O limitador fica fora do caminho usado para aprender.

Saída linearu = Σ(wᵢxᵢ) + bErro, custo e atualizaçãoeA = d − u
E = ½eA²
wᵢ ← wᵢ + ηeAxᵢ
b ← b + ηeA
Como u é contínuo, o erro também mostra a distância numérica entre a saída linear e o alvo.

O QUE MUDA NA CONTA?

A mesma amostra calculada pelos dois métodos

Para isolar apenas a diferença entre as regras, usamos o exemplo binário da página do Perceptron: x₁ = 1, x₂ = 0, resposta correta y = d = 0, w₁ = 0,40, w₂ = −0,20, b = −0,10 e η = 0,20.

d

O que significa d?

d vem de desired output: é a saída desejada, isto é, a resposta correta fornecida pelo conjunto de treinamento. Ela não é calculada pela ADALINE.

Nesta mesma amostra, o Perceptron chama a resposta correta de y = 0, enquanto a notação tradicional da ADALINE escreve d = 0. Portanto, y e d têm o mesmo valor e cumprem o mesmo papel; somente o nome do símbolo mudou.

A linha que realmente muda é a do erro: o Perceptron usa y − ŷ; a ADALINE usa d − u. Como esse valor multiplica a taxa de aprendizado, as entradas e o ajuste do bias, todos os novos parâmetros também ficam diferentes.

01 · FUNDAMENTOS DA ADALINE

Onde entram o erro quadrático e a Regra Delta?

Esses conceitos pertencem ao aprendizado da ADALINE. Diferentemente do Perceptron clássico, ela calcula o erro usando a saída linear antes do limitador.

Entradasx₁, x₂, …, xₙ
→
Saída linearu = Σ(wᵢxᵢ) + b
→
Erro lineare = d − u
→
Erro quadráticoE = ½e²
→
Regra Deltawᵢ ← wᵢ + ηexᵢ

1. O erro vem antes do limiar

A ADALINE compara a resposta desejada d com o potencial linear u. O sinal usado para classificar não participa do cálculo do erro de treinamento.

Saída linearu = Σᵢ(wᵢxᵢ) + bErro lineare = d − u

2. Erro quadrático da amostra

Ele transforma erros positivos e negativos em valores não negativos e penaliza mais intensamente erros de maior magnitude.

FórmulaE = ½e²Exemplo para e = −1E = ½(−1)² = 0,50

3. Somatória sobre o conjunto

A função de custo reúne os erros das N amostras. O treinamento procura pesos que diminuam esse total.

Soma dos erros quadráticosJ(w,b) = ½ Σₚ₌₁ᴺ eₚ²Erro quadrático médioMSE = (1/N) Σₚ₌₁ᴺ eₚ²

4. Regra Delta / LMS

O gradiente informa como cada parâmetro altera o custo. A descida do gradiente move pesos e bias no sentido que tende a reduzir o erro quadrático.

Gradientes da amostra∂E/∂wᵢ = −exᵢ
∂E/∂b = −eAtualizaçãowᵢ ← wᵢ + ηexᵢ
b ← b + ηe
ADALINE × Perceptron: as fórmulas de atualização podem parecer semelhantes, mas o erro é calculado em pontos diferentes. O Perceptron usa a decisão binária ŷ; a ADALINE usa a saída contínua u e minimiza uma função de custo quadrática.

02 · EXEMPLO COMPLETO

Uma atualização da ADALINE, conta por conta.

Na comparação anterior usamos alvos 0/1 para repetir o exemplo do Perceptron. Agora aplicamos a mesma Regra Delta com a notação bipolar histórica da ADALINE: x = [1, 0], d = −1, w₁ = 0,40, w₂ = −0,20, b = −0,10 e η = 0,20.

1 · Saída linear
u = (0,40 × 1) + (−0,20 × 0) − 0,10
u = 0,30
2 · Erro e custo
e = d − u = −1 − 0,30 = −1,30
E = ½(−1,30)² = 0,845
3 · Correções
Δw₁ = 0,20 × (−1,30) × 1 = −0,26
Δw₂ = 0,20 × (−1,30) × 0 = 0
Δb = 0,20 × (−1,30) = −0,26
4 · Novos parâmetros
w₁′ = 0,40 − 0,26 = 0,14
w₂′ = −0,20
b′ = −0,10 − 0,26 = −0,36
Conferência: com os novos parâmetros, u′ = (0,14 × 1) + (−0,20 × 0) − 0,36 = −0,22. A saída linear se aproximou do alvo d = −1.
