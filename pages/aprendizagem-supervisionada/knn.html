APRENDIZAGEM SUPERVISIONADA · k-NN

Decidir olhando os exemplos mais próximos.

O k-Nearest Neighbors guarda os exemplos rotulados e, diante de uma nova entrada, mede distâncias, seleciona os k vizinhos mais próximos e combina suas respostas.

01 · A IDEIA

Exemplos parecidos tendem a ter respostas parecidas.

O k-NN não aprende uma equação global nem constrói uma árvore durante o ajuste. Seu “treinamento” principal é armazenar os dados preparados; o trabalho pesado ocorre quando uma nova previsão solicita os vizinhos.

Entrada

Uma nova amostra é representada no mesmo espaço das amostras de treino.

q = [x₁, x₂, …, xₙ]

Vizinhança

O algoritmo calcula a distância até os exemplos conhecidos e escolhe os k menores valores.

Nₖ(q) = k mais próximos

Resposta

Classificação usa votação; regressão usa a média dos valores próximos.

voto ou média local
Aprendizagem preguiçosa · lazy learning: quase não existe uma fase de ajuste paramétrico. Isso torna o “treino” simples, mas pode deixar a predição cara, porque é necessário localizar vizinhos na base armazenada.

03 · DISTÂNCIAS

“Próximo” precisa de uma definição matemática.

Euclidiana

Distância em linha reta. É a escolha mais conhecida para variáveis numéricas.

d(x,q)=√Σ(xⱼ−qⱼ)²

Manhattan

Soma os deslocamentos absolutos em cada dimensão.

d(x,q)=Σ|xⱼ−qⱼ|

Minkowski

Generaliza as anteriores. Com p=2 vira Euclidiana; com p=1 vira Manhattan.

d(x,q)=(Σ|xⱼ−qⱼ|ᵖ)¹/ᵖ
Sem escala, a maior unidade domina. Comparar renda em milhares com idade em dezenas faz a renda controlar quase toda a distância. O scaler deve ser ajustado apenas no treino e aplicado sem reajuste aos dados futuros.

05 · O VALOR DE k

Uma decisão local demais ou ampla demais.

k pequeno

Fronteira muito local, sensível a ruído e outliers. Em especial, k=1 pode memorizar o treino.

menor viés · maior variância

k intermediário

Combina exemplos próximos e costuma produzir uma decisão mais estável.

escolher por validação

k grande

A vizinhança pode misturar regiões diferentes e favorecer a classe majoritária global.

maior viés · menor variância
Usar k ímpar pode reduzir empates em classificação binária, mas não garante que nunca haverá empate. Pesos, múltiplas classes e distâncias iguais ainda exigem uma regra de desempate.

06 · VOTO UNIFORME OU PONDERADO

Todos votam igual ou os mais próximos falam mais alto.

Peso uniforme

Cada vizinho vale um voto, independentemente da distância.

voto(c) = Σ 1[yᵢ=c]

No exemplo: A recebe 2 votos e B recebe 1.

Peso pela distância

Um vizinho muito próximo pode contribuir mais. Adicionamos ε para evitar divisão por zero.

pesoᵢ = 1 ÷ (dᵢ + ε)
voto(c) = Σ pesoᵢ·1[yᵢ=c]
B: 1÷1,414 ≈ 0,707A: 1÷2,236 + 1÷2,236 ≈ 0,894ŷ = A

07 · CLASSIFICAÇÃO E REGRESSÃO

O mecanismo de busca é o mesmo; a agregação muda.

k-NN Classificador

Escolhe a classe mais frequente ou de maior peso na vizinhança.

ŷ = moda(yᵢ dos vizinhos)

k-NN Regressor

Calcula a média simples ou ponderada das respostas contínuas.

ŷ = (1/k)Σyᵢ

Exemplo de regressão

Consumos dos três carros mais parecidos: 10, 12 e 11 km/L.

ŷ=(10+12+11)÷3=11 km/L

09 · ALGORITMO EM JAVASCRIPT

Distância e classificação em funções separadas.

O exemplo usa arrays simples. Primeiro mede todas as distâncias; depois seleciona os menores valores e conta os votos.

knn-didatico.jsfeito sem biblioteca
function distanciaEuclidiana(a, b) {
  var soma = 0;

  for (var i = 0; i < a.length; i++) {
    var diferenca = a[i] - b[i];
    soma = soma + diferenca * diferenca;
  }

  return Math.sqrt(soma);
}

function ordenarPorDistancia(distancias) {
  // Ordenação simples: compara pares vizinhos e troca suas posições.
  for (var volta = 0; volta < distancias.length; volta++) {
    for (var i = 0; i < distancias.length - 1; i++) {
      if (distancias[i][0] > distancias[i + 1][0]) {
        var temporario = distancias[i];
        distancias[i] = distancias[i + 1];
        distancias[i + 1] = temporario;
      }
    }
  }
}

function classificarKNN(dados, classes, consulta, k) {
  var distancias = [];

  // Guarda distância, classe e posição de cada exemplo.
  for (var i = 0; i < dados.length; i++) {
    distancias.push([distanciaEuclidiana(dados[i], consulta), classes[i]]);
  }

  // Coloca o vizinho mais próximo na primeira posição.
  ordenarPorDistancia(distancias);

  var votosA = 0;
  var votosB = 0;
  for (var vizinho = 0; vizinho < k; vizinho++) {
    if (distancias[vizinho][1] === 'A') votosA = votosA + 1;
    else votosB = votosB + 1;
  }

  if (votosA > votosB) return 'A';
  return 'B';
}
