APRENDIZAGEM SUPERVISIONADA · RANDOM FOREST

Várias árvores diferentes decidem melhor juntas.

Random Forest é um método de ensemble: treina muitas árvores de decisão com amostras e características sorteadas e combina suas respostas para reduzir a instabilidade de uma árvore isolada.

01 · POR QUE ELA EXISTE?

Uma árvore entende regras; uma floresta reduz sua variância.

Uma árvore profunda pode mudar bastante quando pequenas alterações são feitas no conjunto de treino. A floresta cria árvores diferentes e agrega suas respostas, fazendo com que parte dos erros individuais se cancele.

Árvore individual

É fácil de visualizar, mas pode memorizar detalhes e ruídos do treinamento.

pequena mudança → outra árvore

Diversidade

Cada árvore recebe uma visão diferente das linhas e das características disponíveis.

erros menos correlacionados

Agregação

Votação na classificação ou média na regressão torna a resposta mais estável.

muitas respostas → previsão final
Ensemble não significa simplesmente duplicar a mesma árvore. Árvores idênticas cometeriam os mesmos erros. O ganho vem da combinação entre árvores úteis e diferentes.

Amostras Out-of-Bag · OOB

As linhas não sorteadas podem avaliar aquela árvore. Reunindo as previsões feitas somente por árvores que não viram cada amostra, obtemos uma estimativa OOB.

36
erro OOB = erros nas previsões fora da amostra ÷ previsões OOB
OOB não transforma treino em teste final. É uma estimativa interna útil quando há bootstrap, mas um conjunto de teste separado continua necessário para a avaliação final do projeto.

03 · VOTAÇÃO COMPLETA

Classificação escolhe a classe; regressão calcula a média.

Árvore 1✓Sim
Árvore 2✓Sim
Árvore 3✕Não
Árvore 4✓Sim
Votação3 × 1ŷ = Sim
classificação: ŷ = moda(T₁(x), T₂(x), …, Tₘ(x))
regressão: ŷ = (1/M) Σ Tⱼ(x)

Exemplo de regressão

Quatro árvores estimaram o preço de um imóvel em milhares de reais.

T₁=280 · T₂=310 · T₃=295 · T₄=315

Média da floresta

ŷ = (280 + 310 + 295 + 315) ÷ 4ŷ = 1.200 ÷ 4ŷ = 300 mil reais
Detalhe de implementação: a votação por classe apresenta a ideia clássica. Algumas bibliotecas, como o scikit-learn, calculam a média das probabilidades produzidas pelas árvores e escolhem a classe com a maior média.

06 · IMPORTÂNCIA E INTERPRETAÇÃO

A floresta indica sinais, não prova causas.

Redução de impureza · MDI

Soma quanto cada variável reduziu a impureza nas árvores e calcula uma média.

rápida, calculada no treino

Permutation importance

Embaralha uma variável e mede quanto o desempenho cai em dados de validação.

Iⱼ = score − score_embaralhado

Importância não é causalidade

Uma variável pode ser útil por correlação, vazamento ou associação com outra variável.

prever ≠ causar
Cuidado com a importância baseada em impureza: ela pode favorecer características com muitos valores possíveis e descreve o ajuste no treino. Para interpretar generalização, prefira complementar com permutação em validação e conhecimento do domínio.

07 · QUANDO USAR?

Um baseline forte para dados tabulares.

Crédito e risco

Classificação ou estimativa usando renda, histórico e comportamento.

Fraude

Interações não lineares entre valores, horários, dispositivos e frequência.

Manutenção

Falha de equipamento a partir de sensores e condições operacionais.

Preços e demanda

Regressão tabular com relações não lineares e interações.

VantagensLimitaçõesPreparação

08 · ALGORITMO EM JAVASCRIPT

A ideia da votação com arrays.

As árvores já treinadas devolvem classes. Esta função simples conta os votos e escolhe a classe mais frequente.

random-forest-didatico.jsvotação sem bibliotecas
// Cada posição guarda a previsão de uma árvore.
var previsoes = ['Sim', 'Sim', 'Não', 'Sim'];

function votar(previsoes) {
  var classes = [];
  var votos = [];

  for (var i = 0; i < previsoes.length; i++) {
    var posicao = classes.indexOf(previsoes[i]);

    if (posicao === -1) {
      classes.push(previsoes[i]);
      votos.push(1);
    } else {
      votos[posicao] = votos[posicao] + 1;
    }
  }

  var vencedora = 0;
  for (var j = 1; j < votos.length; j++) {
    if (votos[j] > votos[vencedora]) vencedora = j;
  }

  return classes[vencedora];
}
