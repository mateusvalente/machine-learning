0 · EXPLICAÇÃO ESTRUTURADA DO ALGORITMO

Como funciona o Algoritmo do Tamagotchi (Q-Learning Passo a Passo)

Entenda a lógica completa em 6 passos encadeados antes de usar o simulador abaixo.

PASSO 1

1. O Tabuleiro: A Matriz de Fome × Energia

O algoritmo enxerga a vida do Tamagotchi como uma matriz de 11 × 11 (121 quadrados no total):

  • Linhas: nível de Fome de 0 (cheio) até 10 (faminto).
  • Colunas: nível de Energia de 0 (exausto) até 10 (hiperativo).
  • A posição atual do bichinho nesse tabuleiro é o seu Estado atual (s). Por exemplo, se ele está com Fome 5 e Energia 5, ele está parado no quadrado (5, 5).
PASSO 2

2. O que fica guardado em cada quadrado: As 3 Notas

Em vez de guardar uma nota só, cada quadrado da matriz guarda 3 notas separadas — uma para cada ação (botão) que a IA pode escolher quando estiver parada ali:

  • Nota A (Alimentar): o quão bom é dar comida estando nesse quadrado.
  • Nota D (Dormir): o quão bom é colocar para dormir estando nesse quadrado.
  • Nota I (Ignorar): o quão bom é não fazer nada estando nesse quadrado.
No começo, a IA não sabe nada, então todas as 3 notas de todos os 121 quadrados começam zeradas (0.00).
PASSO 3

3. Ação e Consequência: Mexe nos níveis e Pontua

A cada rodada, quando o algoritmo escolhe uma das 3 ações, acontecem duas coisas:

1. Mexe nos níveis de Fome e Energia (fazendo o Tamagotchi andar para outro quadrado da matriz):

  • 🍖 Alimentar: Fome −3 e Energia −1
  • 💤 Dormir: Energia +3 e Fome +1
  • ⏳ Ignorar: Fome +1 e Energia −1
2. Pontua (Recompensa R) de acordo com o novo quadrado onde ele caiu:
• Caiu no centro equilibrado (3 a 7): ganha +10 pontos.
• Caiu na zona de alerta (1, 2, 8 ou 9): perde −1 ponto.
• Bateu nos extremos fatais (0 ou 10): perde −10 pontos (morre/desmaia e reinicia no centro).
PASSO 4

4. Como o algoritmo toma decisões: Greedy + 30% Aleatório que vai caindo (quase uma Meta-Heurística)

Na hora de decidir qual botão apertar, o algoritmo não calcula a Equação de Bellman para cada decisão possível na matriz.

  • Ele olha apenas para o quadrado onde está agora e lê as 3 notas que já estão salvas lá.
  • A regra de decisão é ε-greedy (funciona quase como uma meta-heurística, parecida com o resfriamento do Simulated Annealing):
  • Começa com 30% de chance aleatória (ε = 0.30): No início, 30% das vezes ele chuta uma ação aleatória para explorar o mapa e descobrir o que cada botão faz, e nos outros 70% escolhe a ação de maior nota (Greedy).
  • Vai caindo a cada iteração: Conforme o tempo passa, essa taxa de chute diminui passo a passo (30% → 20% → 10%...) até travar em 2%. Assim, no final, ele toma 98% das decisões indo direto na maior nota.
PASSO 5

5. Onde entra a Equação de Bellman: Atualiza a nota de onde estava

A Equação de Bellman roda só depois que a ação acontece e serve para mudar a nota daquela ação no quadrado onde ele estava:

  • 1. Ele estava no quadrado antigo s, escolheu a ação a e foi parar no novo quadrado s' ganhando a pontuação R.
  • 2. Ele atualiza apenas a nota da ação a daquele quadrado s de onde saiu, somando os pontos que acabou de ganhar com a maior nota disponível no próximo quadrado s':
Nova Nota = Nota Antiga + α · [ Pontos + γ · (Maior Nota do Novo Quadrado) − Nota Antiga ]
PASSO 6

6. O Resultado Final: Padrão de Comportamento Estável

Depois de várias iterações mudando as notas por onde passa, a matriz inteira fica preenchida com notas certeiras:

  • Nos quadrados onde a Fome está alta (7, 8), a maior nota passa a ser 🍖 Alimentar.
  • Nos quadrados onde a Energia está baixa (2, 3), a maior nota passa a ser 💤 Dormir.
  • Nos quadrados do meio (5, 5), a maior nota permite ⏳ Ignorar.
Com isso, o Tamagotchi atinge um padrão de comportamento autônomo que o mantém estável, ficando em um ciclo infinito dentro da zona verde (3 a 7) sem nunca deixar a fome ou a energia baterem nos extremos.

3 · RAIO-X DA ÚLTIMA DECISÃO (MATEMÁTICA PASSO A PASSO)

Substituição numérica na Equação de Bellman

Veja primeiro o que significa cada letra da fórmula e, logo abaixo, acompanhe a conta da última jogada dividida em 4 passos simples.

A EQUAÇÃO DE BELLMAN COMPLETA:
Qnovo(s, a) = Qantigo(s, a) + α · [ R + γ · maxa' Q(s', a') − Qantigo(s, a) ]
1. s e a (Onde estava e o que fez)
• s: Quadrado antigo (Fome, Energia) onde o Agumon estava antes de agir.
• a: O botão que foi apertado (Alimentar, Dormir ou Ignorar).
• Qantigo(s, a): A nota que estava salva naquele botão antes da jogada.
2. s' e R (Para onde foi e pontos)
• s': O novo quadrado para onde o Agumon foi depois que a ação mexeu na Fome e na Energia.
• R (Recompensa): Os pontos ganhos agora por cair em s' (+10 no centro, −1 no alerta ou −10 nos extremos).
3. γ e maxa' Q(s', a') (O Futuro)
• maxa' Q(s', a'): Olhamos as 3 notas lá do novo quadrado s' (A, D e I) e pegamos apenas a maior nota.
• γ (Gamma = 0.90): Peso do futuro (multiplica a maior nota do próximo quadrado por 90%).
4. α e Erro TD (A Correção)
• Alvo: Soma dos pontos de agora (R) com o futuro (γ · max Q(s')).
• Erro (δ): Diferença entre o Alvo e a Nota Antiga.
• α (Alpha = 0.25): Atualiza 25% dessa diferença na nota!
1. Onde estava (s) e Botão apertado (a) s = (5, 5) | a = ignorar
2. Novo Quadrado (s') e Pontos ganhos (R) s' = (6, 4) | R = +10
3. Mudança na Nota Q(s, a) daquele quadrado 0.00 → +2.50 (Δ = +2.50)

Como programar o Q-Learning Tabular do zero

Sem bibliotecas externas: o algoritmo inteiro resume-se a uma tabela de estados, a escolha ε-greedy, a regra de transição do ambiente e a linha da Equação de Bellman.

// 1. ESPAÇO DE AÇÕES E HIPERPARÂMETROS DA EQUAÇÃO DE BELLMAN
const ACOES = ['alimentar', 'dormir', 'ignorar'];
let alpha = 0.25;   // Taxa de aprendizado (learning rate)
let gamma = 0.90;   // Fator de desconto para recompensas futuras
let epsilon = 0.30; // Probabilidade de explorar uma ação aleatória

// 2. INICIALIZAÇÃO DA Q-TABLE: 11 níveis de Fome (0..10) x 11 níveis de Energia (0..10)
const qTable = {};
for (let fome = 0; fome <= 10; fome++) {
  for (let energia = 0; energia <= 10; energia++) {
    qTable[`${fome},${energia}`] = { alimentar: 0.0, dormir: 0.0, ignorar: 0.0 };
  }
}

// 3. POLÍTICA EPSILON-GREEDY: Equilíbrio entre Exploração e Explotação
function escolherAcao(estadoKey) {
  if (Math.random() < epsilon) {
    // EXPLORAÇÃO: testa uma ação aleatória para descobrir novas rotas
    const indiceAleatorio = Math.floor(Math.random() * ACOES.length);
    return ACOES[indiceAleatorio];
  }
  // EXPLOTAÇÃO: escolhe a ação com o maior valor Q(s, a) conhecido
  const valoresQ = qTable[estadoKey];
  return ACOES.reduce((melhor, acao) => valoresQ[acao] > valoresQ[melhor] ? acao : melhor, ACOES[0]);
}

// 4. DINÂMICA DO AMBIENTE E FUNÇÃO DE RECOMPENSA
function executarAcaoNoAmbiente(estado, acao) {
  let { fome, energia } = estado;

  if (acao === 'alimentar') {
    fome = Math.max(0, fome - 3);    // Matar a fome reduz o nível em 3
    energia = Math.max(0, energia - 1); // Digestão consome 1 de energia
  } else if (acao === 'dormir') {
    energia = Math.min(10, energia + 3); // Dormir recupera 3 de energia
    fome = Math.min(10, fome + 1);       // Metabolismo durante o sono dá fome (+1)
  } else if (acao === 'ignorar') {
    fome = Math.min(10, fome + 1);       // Fome sobe naturalmente
    energia = Math.max(0, energia - 1);  // Energia cai naturalmente
  }

  // Cálculo da Recompensa (Reward Shaping):
  // +10 se mantiver Fome e Energia equilibradas entre 3 e 7
  // -10 se deixar chegar nos extremos fatais (0 ou 10)
  const extremo = (fome === 0 || fome === 10 || energia === 0 || energia === 10);
  const equilibrado = (fome >= 3 && fome <= 7 && energia >= 3 && energia <= 7);

  let recompensa = -1; // Zona de alerta intermediária (1, 2, 8, 9)
  if (extremo) recompensa = -10;
  else if (equilibrado) recompensa = +10;

  return { proximoEstado: { fome, energia }, recompensa, fimDeEpisodio: extremo };
}

// 5. ATUALIZAÇÃO PELA EQUAÇÃO DE BELLMAN (Q-LEARNING)
// Q(s,a) <- Q(s,a) + alpha * [ R + gamma * max_a' Q(s',a') - Q(s,a) ]
function atualizarBellman(estadoKey, acao, recompensa, proximoEstadoKey) {
  const qAtual = qTable[estadoKey][acao];
  const maxQFuturo = Math.max(...Object.values(qTable[proximoEstadoKey]));

  const alvoBellman = recompensa + gamma * maxQFuturo;
  const erroTD = alvoBellman - qAtual;

  qTable[estadoKey][acao] = qAtual + alpha * erroTD;
}
