5.1 · FUNDAMENTOS

Dados, atributos e rótulos

O modelo não recebe uma “planilha inteira” de forma abstrata. Ele aprende com exemplos, representa cada exemplo por atributos e, no aprendizado supervisionado, compara sua previsão com um rótulo conhecido.

Uma linha, um exemploAs colunas descrevem o exemplo; uma delas pode guardar a resposta que queremos prever.

VOCABULÁRIO ESSENCIAL

Da tabela para X e y.

Em uma tabela de clientes, cada linha é um exemplo. As colunas úteis para prever formam o vetor de entrada x. A resposta esperada forma o rótulo y.

Exemplo ou amostra

Uma observação individual: um cliente, uma casa, uma imagem ou uma medição.

Atributo · feature

Uma característica usada pelo modelo, como idade, renda ou número de compras.

x = [x₁, x₂, …, xₙ]

Rótulo · label

A resposta conhecida no treino. Pode ser uma classe, como “aprovar”, ou um número, como preço.

y = resposta esperada
Identificador não é automaticamente um atributo. CPF, matrícula e código do cliente normalmente identificam a linha, mas não explicam o fenômeno. Incluí-los sem justificativa pode gerar memorização, vazamento ou relações sem sentido.
