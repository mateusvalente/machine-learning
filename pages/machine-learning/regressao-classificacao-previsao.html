5.1 · FUNDAMENTOS

Regressão, classificação e previsão

Antes de escolher um algoritmo, precisamos identificar o tipo de resposta desejada. Regressão estima números; classificação escolhe categorias; previsão é o resultado que o modelo produz para uma entrada nova.

Comece pela saídaPergunte primeiro: quero obter um valor numérico, uma categoria ou uma probabilidade?

A IDEIA PRINCIPAL

O formato de y define a tarefa.

No aprendizado supervisionado, cada exemplo possui atributos x e uma resposta esperada y. O modelo aprende uma função que transforma x em uma previsão ŷ.

Regressão

Usada quando a saída é um valor numérico contínuo: preço, temperatura, consumo, tempo ou demanda.

ŷ = 438.500 reais

Classificação

Usada quando a saída é uma categoria: spam/não spam, aprovado/reprovado ou uma espécie entre várias.

ŷ = classe “spam”

Previsão · inferência

É a resposta calculada para uma nova entrada. Tanto uma regressão quanto uma classificação produzem previsões.

novo x → modelo → ŷ
“Previsão” não significa apenas descobrir o futuro. Classificar uma imagem já existente como “gato” também é fazer uma previsão. Quando o alvo pertence ao futuro e os exemplos têm ordem temporal, falamos frequentemente em previsão temporal ou forecasting.

Observe a pergunta e o tipo da resposta.

PROBABILIDADE E DECISÃO

Classificar costuma envolver duas etapas.

1. Estimar evidências

O modelo pode calcular probabilidades ou pontuações para as classes.

P(spam | x) = 0,92

2. Aplicar uma regra

Um limiar converte a probabilidade em decisão. Ele pode mudar conforme o custo de cada erro.

0,92 ≥ 0,50 → spam

3. Avaliar o erro certo

Regressão usa métricas como MAE e MSE. Classificação usa matriz de confusão, precisão, recall e F1-score.
