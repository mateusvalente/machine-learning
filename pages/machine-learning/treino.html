MACHINE LEARNING · TREINO

Treinar é transformar erros em ajustes.

Durante o treinamento, o modelo produz previsões, mede o quanto errou e modifica seus parâmetros. Repetir esse ciclo permite encontrar uma configuração que represente melhor os dados.

Acompanhar o ciclo ↓
ForwardEntradas percorrem o modelo e produzem uma previsão.
Erro ou perdaA previsão é comparada com o objetivo do treinamento.
OtimizaçãoPesos e bias são corrigidos para reduzir a perda.

01 · CICLO COMPLETO

Uma atualização acontece passo a passo.

Em aprendizado supervisionado, cada amostra contém uma entrada x e uma resposta correta y.

2. ForwardCalcular ŷ.
→
3. PerdaMedir L(y, ŷ).
→
4. GradienteEncontrar a direção.
→
5. AjusteAtualizar parâmetros.
Uma atualização não encerra o treinamento: o ciclo é repetido para diferentes amostras e durante várias épocas.

02 · ELEMENTOS DO TREINAMENTO

Os termos que aparecem durante o ajuste do modelo.

Parâmetros

Valores aprendidos pelo modelo, como pesos e bias. São modificados pelo algoritmo de otimização.

w e b

Hiperparâmetros

Configurações escolhidas antes ou durante os experimentos, como taxa de aprendizado e tamanho do lote.

η · épocas · batch size

Função de perda

Transforma a qualidade de uma previsão em um valor numérico que o treinamento procura diminuir.

L(y, ŷ)

Gradiente

Indica como uma pequena mudança em cada parâmetro altera a função de perda.

∂L/∂w

Época

Uma passagem completa por todas as amostras do conjunto de treinamento.

1 época = todo o treino

Iteração

Uma atualização dos parâmetros. Uma época pode conter várias iterações.

iterações/época ≈ N ÷ lote

03 · COMO APRESENTAR OS DADOS?

A atualização pode usar uma amostra, um lote ou todo o conjunto.

Estocástico · SGD

Atualiza os parâmetros após cada amostra. Produz muitos ajustes rápidos, mas com maior oscilação.

tamanho do lote = 1

Mini-batch

Calcula o gradiente médio de um pequeno grupo. É a estratégia mais comum em redes neurais.

lote = 16, 32, 64...

Batch completo

Usa todas as amostras antes de atualizar. O gradiente é estável, mas pode exigir muita memória.

lote = N amostras

04 · TAXA DE APRENDIZADO

O tamanho do passo altera o caminho da otimização.

η muito pequeno

Os passos são seguros, mas o treinamento pode ficar excessivamente lento.

η adequado

Os passos reduzem o erro com velocidade sem ultrapassar repetidamente o mínimo.

η muito grande

Os passos ultrapassam o mínimo, podem oscilar e até fazer a perda aumentar.

06 · QUANDO PARAR?

Convergência e generalização precisam ser observadas juntas.

Sinais de convergência

O treinamento está estabilizando quando:

  • A perda varia muito pouco entre épocas.
  • Os parâmetros recebem ajustes cada vez menores.
  • As métricas deixam de melhorar de forma relevante.
  • O limite planejado de épocas é alcançado.

Parada antecipada

O treinamento é interrompido quando a validação deixa de melhorar por determinado número de épocas.

  • Monitora uma métrica de validação.
  • Guarda os parâmetros do melhor momento.
  • Evita continuar decorando o conjunto de treino.
  • Reduz tempo e custo computacional.

IDEIA PARA LEVAR

Treinar não significa apenas repetir épocas.

É preciso acompanhar a perda, escolher uma taxa adequada, avaliar em dados separados e interromper o processo no momento em que o modelo generaliza melhor.
