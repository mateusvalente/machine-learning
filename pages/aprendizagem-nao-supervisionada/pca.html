PCA · REDUÇÃO DE DIMENSIONALIDADE

Como transformar muitas colunas em poucas

O objetivo do PCA não é “apagar colunas”. Ele cria novas dimensões que resumem as variáveis originais e tenta preservar o máximo possível da informação contida nos dados.

A ideia em uma linha

3 variáveis→ PCA→ 2 componentes

Menos dimensões para representar praticamente o mesmo padrão dos dados.

1 · O PROBLEMA

Por que reduzir dimensionalidade?

Em Machine Learning, cada coluna pode representar uma dimensão. Com poucas colunas isso é simples; com dezenas, centenas ou milhares, analisar, visualizar e processar os dados pode ficar mais difícil.

1

Visualização

É fácil desenhar dados em 2D ou 3D. Com 50 variáveis, não existe uma visualização espacial direta.

2

Redundância

Variáveis diferentes podem carregar informações parecidas. O PCA tenta concentrar padrões relacionados em menos componentes.

3

Processamento

Menos dimensões podem significar menos dados para armazenar, transmitir e fornecer a outros algoritmos.

Ideia central: reduzir dimensionalidade significa representar os mesmos objetos usando menos números, tentando perder o mínimo possível da estrutura dos dados.

1 · Espaço originalTrês variáveis = três dimensões.

3 · ProjeçãoOs pontos são representados nesse plano de duas dimensões.

5 · COMO O PCA FAZ ISSO?

Visão superficial do algoritmo

Não precisamos fazer as contas manualmente para entender o processo. Conceitualmente, o PCA faz quatro coisas.

1

Centraliza os dados

Move o conjunto para ficar centrado em torno da média.

2

Encontra os padrões principais

Descobre as direções em que os dados apresentam maior variação.

3

Ordena por importância

PC1 preserva mais variação, depois PC2, depois PC3 e assim por diante.

4

Projeta os dados

Mantém apenas a quantidade de componentes escolhida e gera uma nova tabela reduzida.

Para esta aula, basta guardar: o PCA procura novos eixos que resumam os dados. Nós escolhemos quantos desses eixos queremos manter.

6 · USANDO UMA BIBLIOTECA

Fazendo 3D → 2D com scikit-learn

A biblioteca executa a parte matemática. Nós informamos os dados e dizemos que queremos apenas 2 componentes.

Python · scikit-learnPCA(n_components=2)
import numpy as np
from sklearn.decomposition import PCA

# 6 alunos × 3 variáveis
X = np.array([
    [9, 8, 9],
    [8, 8, 7],
    [7, 6, 8],
    [4, 5, 4],
    [3, 4, 3],
    [2, 3, 2]
])

# Quero reduzir de 3 dimensões para 2
pca = PCA(n_components=2)

# Aprende os componentes e já transforma os dados
X_reduzido = pca.fit_transform(X)

print(X_reduzido)
print(pca.explained_variance_ratio_)
print(pca.explained_variance_ratio_.sum())

Atenção à escala: o `PCA` do scikit-learn centraliza os dados, mas não padroniza automaticamente cada variável. Neste exemplo, as três notas estão na mesma escala. Em bases com unidades muito diferentes, normalmente avaliamos a padronização antes do PCA.

7 · RESUMO

O que você precisa lembrar

01

PCA cria novas dimensões

Ele não simplesmente escolhe algumas colunas da tabela original.

02

As primeiras são as mais importantes

PC1, PC2, PC3... aparecem ordenados pela quantidade de variação que conseguem representar.

03

Reduzimos mantendo as primeiras

Escolhemos menos componentes quando eles preservam uma quantidade aceitável da informação.

Em uma frase: PCA é uma técnica que troca muitas variáveis por um conjunto menor de componentes, tentando preservar o máximo possível da variação presente nos dados.
