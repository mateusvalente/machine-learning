PCA · PRINCIPAL COMPONENT ANALYSIS

PCA começando pela imagem mental

Antes de calcular qualquer coisa, vamos entender quatro objetos diferentes: dados, matriz de covariância, autovetor e autovalor. Depois veremos como eles permitem transformar três dimensões em duas.

1Entender o que é vetor e o que é número.
2Ler a matriz de covariância linha por linha.
3Descobrir as direções especiais da nuvem.
4Projetar 3D em um plano 2D.

PRIMEIRO: TIRE ESTA DÚVIDA

Autovetor é vetor? E autovalor?

Sim: autovetor é realmente um vetor. Já autovalor não é vetor: é um único número, um escalar, associado àquele autovetor.

Autovetor = vetor

Ele tem componentes. Em três dimensões, por exemplo:

v₁ = [0,638 ; 0,443 ; 0,630]

Esses três números descrevem uma direção no espaço 3D.

Autovalor = número

Ele é um valor associado ao autovetor:

λ₁ = 20,31

No PCA, para um autovetor unitário da matriz de covariância, esse número representa a variância existente naquela direção.

ANTES DO PCA: ENTENDA O “AUTO”

O que torna um vetor um autovetor?

Uma matriz pode ser vista como uma transformação. Ela recebe um vetor e devolve outro. A maior parte dos vetores muda de tamanho e de direção. Um autovetor é especial: depois da transformação, ele continua sobre a mesma linha.

Vetor comum

O resultado A·u não está na mesma linha de u. Portanto, u não é autovetor de A.

VERSUS
Autovetor

A transformação apenas escala v. Por isso vale A·v = λv. v é o autovetor; λ é o número que diz o quanto ele foi escalado.

Agora faça a ponte com PCA: no nosso caso, a matriz A será a matriz de covariância Σ. Os autovetores de Σ fornecem as direções principais da nuvem. Os autovalores dizem quanta variância existe em cada uma dessas direções.

PASSO 3 · DA MATRIZ PARA AUTOVALORES E AUTOVETORES

Como a matriz de covariância produz os novos eixos do PCA?

Aqui está a ponte que normalmente fica escondida. A matriz de covariância não se transforma diretamente em um vetor. Nós fazemos duas buscas matemáticas: primeiro encontramos os autovalores λ; depois, para cada λ, encontramos o autovetor v que satisfaz Σv = λv.

Leia assim: Σ contém as variâncias e covariâncias das três variáveis. Procuramos uma direção v = [vM, vF, vP] que, ao ser multiplicada por Σ, continue apontando para a mesma direção. Quando isso acontece, v é um autovetor e o fator de aumento/redução é o autovalor λ.
1 · Começamos com ΣAs linhas e colunas são Matemática, Física e Programação.Σ = matriz 3 × 3
2 · Encontramos λBuscamos os valores que tornam a matriz Σ − λI singular.det(Σ − λI) = 0
3 · Encontramos vPara cada λ, resolvemos o sistema que encontra uma direção não nula.(Σ − λI)v = 0
4 · ConferimosA multiplicação linha × coluna deve gerar o mesmo vetor apenas escalado.Σv = λv

O que cada posição do autovetor significa?

Em v₁ = [0,638; 0,443; 0,630], a primeira posição pertence à coluna Matemática, a segunda à Física e a terceira à Programação. O vetor não pertence a uma única célula da matriz: ele é uma direção que combina todas as variáveis.

v = [ peso de M ; peso de F ; peso de P ]

E por que λ vira “variância explicada”?

Como Σ é uma matriz de covariância e usamos autovetores de comprimento 1, o autovalor associado mede a variância dos dados quando olhamos exatamente naquela direção. Por isso λ₁ grande significa que PC1 captura muito mais espalhamento que PC2 ou PC3.

variância na direção v = vᵀΣv = λ, quando ‖v‖ = 1

EM UMA FRASE

O que o PCA fez?

Ele não testou 50 colunas “uma contra a outra” para escolher vencedoras. Ele usou as relações entre todas as variáveis para encontrar um novo sistema de eixos. Os autovetores definem esses eixos; os autovalores dizem quanta variância cada eixo carrega; então mantemos os eixos mais informativos e projetamos os dados neles.

CHECAGEM DE ENTENDIMENTO

Quatro perguntas que devem estar claras agora

1. O autovalor é um vetor?

Não. O autovalor λ é um único número. O autovetor v é o vetor.

2. O que cada linha e coluna da covariância representa?

Uma variável original. A célula (linha Matemática, coluna Física), por exemplo, é Cov(Matemática,Física). Na diagonal, uma variável é comparada com ela mesma e obtemos sua variância.

3. Por que o maior autovalor vira PC1?

Porque, para a matriz de covariância, o autovalor associado a um autovetor unitário é a variância dos dados naquela direção. O maior λ identifica a direção de maior variância.

4. Reduzir 3D para 2D significa excluir uma coluna original?

Não. Significa trocar o sistema de coordenadas original por PC1, PC2 e PC3 e depois manter apenas PC1 e PC2.

DEPOIS DA INTUIÇÃO · CÓDIGO DIDÁTICO

Implementação sem chamar uma função PCA pronta

Abaixo, o código constrói a covariância manualmente e usa o método da potência para aproximar autovetores. O objetivo é mostrar as etapas, não substituir bibliotecas numéricas de produção.

Abrir implementação Python do zero
pca_do_zero.py · sem sklearn / sem PCA()
def media_colunas(dados):
    n = len(dados)
    p = len(dados[0])
    medias = []

    for j in range(p):
        soma = 0.0
        for i in range(n):
            soma += dados[i][j]
        medias.append(soma / n)

    return medias


def centralizar(dados, medias):
    resultado = []

    for linha in dados:
        nova = []
        for j in range(len(linha)):
            nova.append(linha[j] - medias[j])
        resultado.append(nova)

    return resultado


def covariancia(dados_centralizados):
    n = len(dados_centralizados)
    p = len(dados_centralizados[0])
    matriz = [[0.0 for _ in range(p)] for _ in range(p)]

    for a in range(p):
        for b in range(p):
            soma = 0.0
            for i in range(n):
                soma += dados_centralizados[i][a] * dados_centralizados[i][b]
            matriz[a][b] = soma / (n - 1)

    return matriz


def multiplicar_matriz_vetor(A, v):
    resultado = []
    for linha in A:
        soma = 0.0
        for j in range(len(v)):
            soma += linha[j] * v[j]
        resultado.append(soma)
    return resultado


def normalizar(v):
    norma = sum(x*x for x in v) ** 0.5
    return [x / norma for x in v]


def produto_escalar(a, b):
    return sum(a[i] * b[i] for i in range(len(a)))


def autovetor_dominante(A, iteracoes=200):
    # Palpite inicial: qualquer vetor não nulo.
    v = normalizar([1.0 for _ in range(len(A))])

    # Repetir A·v e normalizar faz v convergir
    # para a direção associada ao maior autovalor.
    for _ in range(iteracoes):
        Av = multiplicar_matriz_vetor(A, v)
        v = normalizar(Av)

    Av = multiplicar_matriz_vetor(A, v)
    autovalor = produto_escalar(v, Av)

    return autovalor, v


def projetar(ponto_centralizado, autovetor):
    return produto_escalar(ponto_centralizado, autovetor)


dados = [
    [9, 8, 9],
    [8, 8, 7],
    [7, 6, 8],
    [4, 5, 4],
    [3, 4, 3],
    [2, 3, 2]
]

medias = media_colunas(dados)
X = centralizar(dados, medias)
Sigma = covariancia(X)

lambda1, v1 = autovetor_dominante(Sigma)

print("Médias:", medias)
print("Matriz de covariância:", Sigma)
print("Maior autovalor:", lambda1)
print("Primeiro autovetor / PC1:", v1)

for ponto in X:
    print("score PC1 =", projetar(ponto, v1))

De onde veio esta forma de explicar?

Victor Powell & Lewis Lehe — Explained Visually: Principal Component Analysis. A ideia de visualizar PCA como um novo sistema de coordenadas e, em 3D, como encontrar o melhor “ângulo” para projetar os dados.

3Blue1Brown — Eigenvectors and Eigenvalues. A interpretação de autovetores como direções que permanecem sobre a mesma linha durante uma transformação, com λ atuando como fator escalar.

scikit-learn — PCA. Os componentes são eixos no espaço das features ordenados por variância explicada; os maiores autovalores da covariância correspondem à variância explicada.

Built In — PCA step-by-step. Interpretação da matriz de covariância: diagonal como variâncias e elementos fora da diagonal como covariâncias entre pares.
